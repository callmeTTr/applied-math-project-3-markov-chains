# Đồ án 3 — Xích Markov

Hai bài toán xác suất sử dụng xích Markov. Câu 1 xét phần dư của tổng các lần tung xúc xắc theo modulo 7. Câu 2 xét hành trình của Drogon, phân phối dừng, kỳ vọng số lần ở nhà và mô phỏng.

Bài làm môn Toán ứng dụng và Thống kê của Phan Anh Đức và Trịnh Văn Thành.
Thông tin nhóm và phần trình bày gốc được giữ trong notebook và báo cáo.

## Chạy notebook

Mở terminal tại thư mục repo và chạy trên Windows.

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m jupyterlab
```

Mở notebook và chạy các ô theo thứ tự từ trên xuống. Giữ thư mục làm việc tại
gốc repo để notebook đọc đúng ảnh hoặc dữ liệu đi kèm.
